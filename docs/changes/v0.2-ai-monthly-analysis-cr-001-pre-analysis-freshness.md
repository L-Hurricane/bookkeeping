## Rule

用户发起新的 AI 分析生成（AI Analysis Generation）时，后端必须确认：用户当前已查看的月度上下文（Monthly Context），仍然与服务器当前月度上下文（Current Monthly Context）一致。

一致：允许继续生成。

不一致：返回 `REFRESH_REQUIRED`。

`REFRESH_REQUIRED`：

- 不调用外部大语言模型（No LLM Call）
- 不创建快照（No Snapshot）
- 不消耗产品配额（No Product Quota Consumption）
- 用户先刷新当前月份
- 刷新后不自动生成
- 用户查看最新数据后，重新主动点击分析

MVP 只判断变化或未变化（Changed / Not Changed）。

不实现：变化了什么（What Changed）、谁改的（Who Changed）、审计轨迹（Audit Trail）。多设备审计、家庭账户审计轨迹和变更历史以后单独走产品变更。

如果数据期间发生过变化，但最终上下文又完全恢复一致，允许继续生成。

比较的是用户看到的分析输入与服务器当前分析输入是否一致。

具体的新鲜度令牌（Freshness Token）、指纹（Fingerprint）或版本（Version）机制尚未冻结。
