# v1.0 · S2 UAT-02 · 新建转账账户选择

Status: Accepted

Feature: 账户间转账（Transfer）

Change: 新建转账时转入账户不自动填写

本文件是 2026-10-25 负责人复验后的最小补充。它不替换、不改写下列原件，也不沿用它们的 SHA：

- `docs/product/bookkeeping-v1.0-product-baseline-v1.0.md`
- `docs/product/bookkeeping-v1.0-ui-freeze-v1.0.md`

UI Freeze 仍要求转账使用两个不同账户，并保留两侧时间、保存后返回和整笔修改、删除。产品基线 TRF-02 仍要求两个不同的正常账户。本补充只确定新建页面的默认选择。

## 负责人确认

负责人于 2026-10-25 确认，当时小程序里的实际交互就是最终接受方案：

- 从正常账户进入新增转账，转出账户默认当前账户。
- 转入账户始终不自动填写，包括只有一个可选转入账户时。
- 用户必须主动选择转入账户。
- 编辑已有转账仍按已保存数据回填。
- 双方账户不能相同，且必须是正常可用账户。

不新增账户偏好、数据库字段或别的基础设施。
