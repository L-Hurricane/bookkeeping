# 本地验收测试数据 v1

只用于本地人工验收。默认关闭。普通 `./mvnw spring-boot:run` 不会创建、删除或修改这些数据。

密码从环境变量 `ACCEPTANCE_TEST_PASSWORD` 读取。不要把它写入 Java、Git 配置、README 或日志。未提供或为空时命令失败。

## 安全边界

同时满足才运行：

- Spring profile 为 `local`
- `ACCEPTANCE_DATA_ENABLED=true`

`prod` 或 `production` profile 下即使误设环境变量也不运行。脚本会强制 `local`。命令使用 Servlet ApplicationContext，以便正式 Security 配置能够创建 `HttpSecurity`；同时设置 `server.port=-1`，不监听 HTTP 端口，也不占用本地 8080。

`reset` 只删除下表用户及其业务数据，不清理整个数据库，也不删除其他本地用户。

## 固定用户

| 用户名 | 场景 |
|---|---|
| `accept_empty` | 用户存在，无 Account |
| `accept_zero` | 微信 / CNY，Opening Balance `0.00`，无 Transaction / BalanceAdjustment |
| `accept_positive` | Opening Balance `50.00`，无 Transaction / BalanceAdjustment |
| `accept_negative` | Opening Balance `-100.00`，无 Transaction / BalanceAdjustment |
| `accept_ledger` | Opening Balance `1000.00`，固定流水与一笔余额调整 |

## accept_ledger

业务时间均为北京时间。B 与 C 的业务时间相同，创建顺序是 B 然后 C。

| 标记 | 业务时间 | 类型 | 金额 | 分类 |
|---|---|---|---|---|
| A | 2026-08-31T23:59:00+08:00 | EXPENSE | 10.00 | 餐饮 / 其他 |
| B | 2026-09-05T09:00:00+08:00 | EXPENSE | 35.50 | 餐饮 / 其他 |
| C | 2026-09-05T09:00:00+08:00 | INCOME | 200.00 | 其他收入 |
| D | 2026-09-12T20:00:00+08:00 | EXPENSE | -20.00 | 无分类 |
| E | 2026-10-01T00:00:00+08:00 | INCOME | 88.00 | 其他收入 |
| F | 2026-09-20T12:00:00+08:00 | BalanceAdjustment | targetBalance 1300.00 | 差额由正式余额调整计算 |

没有新增产品分类。D 是 v0.2 允许的未分类 Transaction。

账户创建时间会被固定为 `2026-08-01 00:00:00`（北京时间语义），使上述历史业务时间能够通过“不得早于账户创建时间”的正式规则。重复 `reset-and-seed` 得到同一基线。

## 命令

本机需要已经准备好 Java 和数据库环境。当前项目可先载入本地私有环境，再执行脚本。`ACCEPTANCE_TEST_PASSWORD` 只放在这份私有环境或当前 shell 中，不进入 Git。下面的路径是当前项目本机示例，脚本本身不写死个人绝对路径。

```sh
set -a
source ~/.config/bookkeeping/bootstrap.env
set +a
ACCEPTANCE_TEST_PASSWORD='...' ./scripts/acceptance-data.sh reset
ACCEPTANCE_TEST_PASSWORD='...' ./scripts/acceptance-data.sh seed
ACCEPTANCE_TEST_PASSWORD='...' ./scripts/acceptance-data.sh reset-and-seed
```

脚本会设置 `BOOTSTRAP_USER_ENABLED=false`，因此调用者 shell 里残留的 Bootstrap User 配置不会在这条命令中创建普通引导用户。

`seed` 要求这些用户尚不存在。要恢复到同一基线，使用 `reset-and-seed`。

成功时只打印操作结果、用户名和场景名。
