### 2.1 明确不作为本轮强制需求的细节

- 首页搜索是账户搜索图标还是独立栏：优先复用交易页搜索；**不要求首页再提供第二套账户/交易混合搜索**。
- 时间“今天、上季、最近90天、所有时间”等大量快捷项及图表类型切换：不在 v1.0 第一轮增加。`更多 → 自定义时间`可覆盖绝大多数特殊情况。
- 图表展示粒度、金额格式和触点具体像素：属于未冻结实现细节，由组长在不改变业务语义前提下决策并在 Gate 验证；不为了视觉效果添加额外复杂统计。
- 新增「我的预算、预约、预测、投资组合」及取消旧单账户 AI 入口：本轮不做。

## 4. 已确认的稳定业务事实（本轮不得改变）

- `AC-04/05/07/08/09`：起始金额已保存后不可直接回写；归档历史保留，永久删除不可恢复且需跨账户影响预览/事务一致。
- `TX-05/06`：已保存收入/支出类型不能切换；流水按业务时间 DESC、首次保存序 DESC；未来业务时间的已保存变动**立即影响当前账面余额**。
- `TRF-05`：转账两侧允许不同业务时间，历史按两侧各自生效，不得让「全部交易」造成统计收支重复。
- `BAL-02/03/05`：余额调整保存固定差额、不是收支；历史记录只查看/删除后重建。其当前账面余额与历史时点余额不能混为一谈。
- `ST-07`：分类带符号金额除以净总额绝对值；负净额代数和-100%，净额0不显示百分比。
- `ST-08/09`：标签重叠覆盖不强凑100%，父标签子树按交易 ID 去重、直接关联独立。
- `AI-01～07 + S5 方案 B`：AI 仍全账本月/年、不继承普通统计的时间/账户过滤；永久删除任一账户后旧 LEDGER 历史报告不可读；每日调用额度/快照不因 UI 改版而改变。

## 6. 验收矩阵（功能、UI、性能、授权）

1. **首页与 FAB**：账本净值/月收支正确且颜色合规；无最近交易；全部交易可进入并返回；FAB 三操作按账户上下文正确打开现有表单，不在归档账户新增。
2. **流水**：全部交易/单账户按业务时间与首次保存序稳定倒序，月份收支不含转账及余额调整；全部交易能识别账户；单账户交易编辑后返回符合 UI Freeze §2.2；无数据、长文本及分页连续性正确。
3. **统计筛选**：自然月/滚动月区分准确，三大模块、分类/标签共享时间/账户范围且归档默认不参与；自定义时间与自定义账户多选生效；AI 全账本月/年规则不受统计筛选干扰。
4. **净值**：期初、期末、变化与现有确定性 S4 统计可对账；转账双时点与负信用账户正确；图表点准确，明细只在点击后分页加载且继承筛选。
5. **分类**：三级/未分类与其子树准确；正向可分解时环形图正确；负值/零净额退化不制造虚假百分比。
6. **标签**：横向条形图，父子多选去重，直接关联/子树区别，无标签顶级桶；不把标签交叠强凑100%。
7. **效率**：常规打开统计页不附带拉取全部期间交易；交易分页，长区间图表有限点数；记录实际请求数量与可复核的延迟/资源表现，不凭估计报“性能提升”。
8. **质量与安全**：维持租户隔离、归档只读、账户删除方案 B、AI 额度与敏感数据边界；实测什么就报告什么，不以旧 T07／CI=0／Stub 冒充新代码或真实供应商 PASS。
