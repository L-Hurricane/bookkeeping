## 1. 调整目的与判断

同意此方向：不要求负责人在 S5 单独真实调用外部模型并操作完整 UAT；集中保留独立自动化质量验证及组长证据判断，业务操作体验留至 v1.0 完整功能完成后的统一人工验收。减少重复人工接力和模型调用成本，不削弱 S5 数据隔离、账务数字、报告持久化、配额、删除规则 B 等核心安全/正确性要求。

本修订**仅改变 S5 的人工里程碑、放行形式和终态表述**；**不改变** AI-01～AI-07、T00～T06 功能/测试范围、独立 Testing/Supervisor、P0/P1 阻断标准、方案 B、现有 Schema/DDL 白名单、Git 安全授权，也**不自动批准** v1.0 最终验收 Stage 或发布。

1. **T06 原计划不变、应立即继续**：独立 Testing 和独立 Supervisor 核对 AI-01～AI-07。重点 MySQL V18 LEDGER/MONTH/YEAR 真实持久化、快照、租约/fencing、并发共用 3 次额度、方案 B 删除影响预览及事务、跨用户隔离和统计确定性。只在已授权、可恢复的隔离库执行；真实供应商优先 Stub，不默认发生付费调用。

3. **最终统一人工验收待办**：记录 `S5-UAT-DEFER-01`（验收类延期，非缺陷、非新增功能），最迟 `v1.0 FINAL HUMAN UAT`：自然月/年选择与历史读取、归档纳入、报告文案与金额一致性、额度/失败反馈、方案 B 用户可见性，以及获批安全条件下真实外部模型效果。如最终真实供应商调用仍无授权，则明确列明未测及发布决策，不伪称完整通过。
4. **现有 Backlog 不变**：`UX-ST-01`（统计体验 + MoneyWiz 对比）、`UI-NAV-01`、`S4-UI-COPY-01` 等原定最终 UI 统一处理事项不提前进入 S5。
