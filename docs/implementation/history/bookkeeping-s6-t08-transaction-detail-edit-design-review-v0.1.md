## 本次新反馈（暂定 UI-FB-018）

1. 当前从账户流水点击记录直接进入编辑页，而编辑页点击「取消」后却进入只读详情页；信息路径不连贯。
2. 负责人**建议**采用「流水 → 只读交易详情 → 手动点编辑 → 编辑交易」；取消编辑返回详情，修改成功也回到详情（示例行为，实际返回策略待最终确认）。
3. 编辑交易页面与现行整体卡片视觉缺少一致性，希望按照已通过的一、二轮浅色轻金融风格收敛。
4. 不删除已存在的交易删除入口、分类/标签树选择、时间和备注等功能；归档账户历史只读。

## 视觉候选

- 流水列表：按当前单账户日分组显示，点击普通交易进入「交易详情」。
- 详情：顶部单笔金额和名称成为视觉主次；下方账户、分类、已选标签和时间分组展示；空备注默认不占空间；底部清晰的「编辑交易」主操作和「删除」次操作。所有金额颜色仍按实际显示值正红负绿。
- 编辑：共用白色卡片、统一字段行、顶部金额、账户、名称、分类/标签、时间/备注；标签仅展示已选值，点开独立多选面板；底部「取消 / 保存修改」。
- 删除：必须确认；不因界面简化取消安全约束。
- 编辑已保存交易的类型、资金账户是否能修改：**严格由当前有效正式 PRD/UI 及现有业务实现核验决定**，不能仅凭原型中的锁定示意擅自扩大/缩小权限。现行 UI Freeze v1.0 §2.2 记有编辑可修改所属账户，而近期 Cursor 回执记有已保存后的资金账户限制，存在需要核对的依据差异。
- 实际页面应在微信开发者工具中按导航、保存、取消、删除等真实事件验证，不能将 HTML 演示当作前端完成。
