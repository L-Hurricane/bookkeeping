### 1.1 FB-016：账户详情与 FAB

- 单账户资金卡移除“普通账户”说明，移除独立“统计”“余额调整”文本操作，但保留必要账户资料、账户设置、余额/时间口径和合法入口。
- 首页、全部交易 FAB：**支出、收入、转账**。
- **正常**单账户流水 FAB：同样三项 + 底部清晰分隔的**调整余额**；入账、出账默认当前账户，转账默认其为转出账户，但在原合法规则内可改选。
- 归档账户不提供 FAB、创建或余额调整；余额调整已保存记录**仍仅能查看／删除并重新建立**；金额正红负绿按实际数值。
- 检查 FAB 展开、收起、遮挡底部导航及滚动时操作可达性。

### 1.2 FB-017：标签独立多选面板

- 新增与编辑普通交易共用「标签」选择入口，表单不平铺所有标签，只展示已选摘要/数目；底部弹层按已有统一设计，标签树完整、可滚动、选中状态清楚，可多选/取消、确认/取消，支持从选择器中**新建标签**。
- 父子标签不隐式级联；回显实际显式关联；取消面板不改变交易表单当前已确认标签；编辑未改动后保存不应丢标签。
- 创建标签属于单独保存的现行规则：即便最终取消交易，新建标签本身保留（PRD TX-03）；界面须清楚反馈。
- 处理多标签、无标签、深层节点、长列表及空态；不得增加新字段或改关联表语义。

### 1.3 FB-018：普通交易列表→详情→编辑

- 对普通收支交易，单账户流水、全部交易、搜索结果和统计明细统一：**点击行进入只读「交易详情」**，再经显式「编辑交易」进入编辑页；详情含「删除」及安全确认。
- 编辑取消返回只读详情；保存成功后刷新详情并返回详情。删除后按来源路径安全返回适当列表，不可留下不存在的详情页。
- 金额、名称/分类/已选标签、账户、业务时间、备注按本轮已批准卡片视觉展示；空备注不要占据大面积空间。新增与编辑表单共享视觉规范。
- **冻结差异明确获批**：这仅取代 UI Freeze v1.0 §2.2 关于普通流水直达编辑、编辑保存返回账户列表的路径。不要据此改变转账、余额调整或归档历史的原合法流程。
- **紧要契约核对**：正式 PRD TX-04 与 UI Freeze §2.2 明确允许普通交易更换所属资金账户；最近实现回执却称保存后锁定账户。先核实真正合同/接口和代码。若证据证明是已冻结能力遗漏，按既定计划做必要兼容修复并测试旧/新账户余额、同一 transaction ID、隔离与归档限制；如发现实质业务/安全冲突，停止受影响改动上报，切勿仅删除警示文字或静默放宽权限。普通交易类型仍不能变更。

### 1.4 FB-019：统一统计账户筛选

- 三个**互斥模式**：默认「未归档账户」、 「全部账户（含已归档）」、 「自选账户」。不可将它们叠加成独立的“包含归档开关+自选清单”；避免粗黑描边的多重选中状态。
- 仅选择「自选账户」时显示可打开的专用多选面板；统计页常驻区域只显示简洁摘要「已选 N 个账户」。面板内未归档在前、已归档在后；各组可折叠/滚动，支持搜索、便捷全选/清空；自选可从两组任意组合，不受另外的归档模式覆盖。
- 自选为空时不能静默回退到全部账户，显示明确空态；切换统计页面/时间范围时在合法状态内保留选择；五类统计、图表、金额、交易下钻范围一致；已归档可选但不使已永久删除账户重新出现。
- **未来账户自定义分组**仅预留松耦合组件结构，不实现账户分组、分组顺序/排序字段、跨组批量选择业务或新 Schema；避免未来功能抢占本次 S6。
