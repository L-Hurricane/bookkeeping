# S6 T05 基础功能体验清单

- 日期：2026-10-27
- 这是负责人查看冻结 UI 和已有业务的试用说明。不是独立质量 Gate，也不是 v1.0 最终人工 UAT。

## 怎么打开

用微信开发者工具打开 `frontend/miniprogram`，连接到已经在用的本地后端。本轮没有启动 Spring，也没有迁移数据库。如果现有后端还没有 V18，全账本 AI 的保存会失败；不要为了这次试用把 V18 迁入 `bookkeeping` 或 `bookkeeping_test`。

## 建议看的路径

1. 底部出现「账本 / 统计 / 我的」。账本页可以创建账户、看归档、进入流水。
2. 「我的」里打开分类管理和标签管理。账户设置里只保留当前账户的更名、归档、恢复和永久删除。
3. 「统计」能切账本净值、收入分析、支出分析。收入或支出下，分类和标签一次只看一边，点一行进入明细。标签可以多选后查看。
4. 从某个账户的流水点「统计」，统计页出现「AI 分析本月」。从底部「统计」进入时，按钮是全账本「AI 分析」。
5. 记一笔、改一笔、转账、余额调整的原路径仍可用。已保存的余额调整仍然不能编辑。金额仍是正红负绿。
