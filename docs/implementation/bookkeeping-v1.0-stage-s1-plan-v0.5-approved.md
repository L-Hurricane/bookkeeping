## 1. S1 完整 Stage 定义（沿用 v0.4）

**S1：多资金账户基础与普通交易跨账户记账。** 同一 User 可创建和使用至少两个资金账户，普通/信用类型可区分，收支交易可从账户 A 改归属到账户 B，起始金额、余额调整和派生余额正确，旧单账户数据无损。延续已有交易 CRUD、搜索、分类/标签和现有小程序结构。

**不在 S1 实施**：转账、账户归档/永久删除、完整三级分类/标签树、全账本历史净值、年度 AI 报告、生产部署和公众上线。以上属于 v1.0 后续范围，不因 S1 关闭而删除。数据库路线仍为保留 Account ID、版本化迁移、余额派生、授权隔离工作区及隔离测试库；生产数据与不可逆迁移不在授权内。
