## 实际功能

S3 交付了分类树和标签树。分类按收入、支出分开，同一类型内名称唯一，最多三级，只有当前叶子可以记账。标签不分收入和支出，同一用户内名称唯一。父标签和子标签可以同时显式关联同一笔交易。删除有子节点的节点会被拒绝。删除叶子分类后交易变为未分类。删除叶子标签只移除该标签关联。交易金额、账户、时间和余额不因这些维护被改掉。

正式结构变化是已批准的 V17。历史 V1–V16 未改。
