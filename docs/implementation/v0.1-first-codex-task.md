# 4. 实现范围

## Project

创建标准 Spring Boot Maven Project。

要求：

- Java 25；
- Spring Boot 4.1.1；
- Maven Wrapper 固定 Maven 3.9.16；
- 单体应用；
- package-by-feature 顶层骨架。

## Dependencies

只加入 Phase 0 已批准依赖。

## Configuration

建立外部化配置：

- DB URL；
- DB username；
- DB password；
- runtime environment。

不得提交真实密码。

允许：

- `application.yml`
- environment override
- test configuration

不要创建复杂配置中心。

## Database

接入 MySQL + Flyway。

本任务：

- 建立 Flyway 目录和集成配置；
- **不要生成 v0.1 业务表 Migration SQL**；
- 不创建 users / accounts / transactions 等正式表。

目标只是验证：

> Spring Boot → MySQL → Flyway 的工程链路可以工作。

如果 Flyway 启动必须存在 Migration，可使用不建立业务表的最小安全 marker，并说明理由。

## Health

启用最小 Health Check。

不要建设完整 Observability Stack。

## Package Skeleton

只建立顶层业务包边界，不写业务类：

```text
identity
account
category
tag
transaction
adjustment
ledger
statistics
common
```

不要为了形式创建大量空 domain/application/repository 类。

# 5. Test

至少验证：

1. Maven Wrapper 可以运行；
2. Java 25 编译；
3. Spring Context 能启动；
4. Test Profile 正常；
5. Flyway 集成可加载；
6. MySQL 连接在配置正确时可验证；
7. Health Check 可访问；
8. `./mvnw test` 全部通过。

数据库测试必须针对 MySQL，不要切成 H2。

如果本机 MySQL 尚未就绪：

- 不要伪造“测试通过”；
- 清楚区分哪些测试实际通过、哪些因环境缺失未执行；
- 给出最小环境准备说明。
