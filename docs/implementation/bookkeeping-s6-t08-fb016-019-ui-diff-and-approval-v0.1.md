### FB-018 与已冻结产品的明确差异

- `bookkeeping-v1.0-ui-freeze-v1.0.md` §2.2 旧规则“普通流水直接打开可编辑表单”“保存后返回账户流水”被本次**普通收支交易详情流**明确替换。
- 其他冻结约束继续有效：按数值正红负绿/零中性（已批准统计聚合中性色例外继续有效）、交易类型保存后不可变、分类选叶子、标签显式多选、交易删除须确认。
- **特别核对潜在旧实现冲突**：正式 PRD TX-04 及 UI Freeze §2.2 允许已保存普通交易修改所属账户，而近期 Cursor 回执称资金账户锁定。**不能将旧实现或文案自动提升为产品规则**。实施前只读核对当前有效批准、后端约束和测试证据：若只是实现缺陷，按正式已批准能力做最小修复及资金影响回归；若发现实质权限/历史事实冲突，停止受影响部分并报告，由组长按保留边界决定是否需负责人追加审批。此核对不是授权改动账务算法。
- 不改变转账两侧时间与编辑、余额调整历史只读、归档账户历史只读等功能边界；账户间付款和统计详情入口在交互上须可达但不随普通交易导航变更擅自重写。
