# S6 T01 冻结 UI 最小落实

- 日期：2026-10-27
- 依据：`docs/product/bookkeeping-v1.0-ui-freeze-v1.0.md` 与 Approved v0.3。不改冻结原件。

| 冻结规则 | 当前缺口 | 落实 |
|---|---|---|
| 主导航「账本 / 统计 / 我的」 | 没有 tabBar。账本工具栏有临时「统计」 | 三个 tab。账本页去掉临时按钮。归档、创建账户、退出登录留在账本 |
| 分类、标签是账本级数据；账户设置只针对当前账户 | 入口只在账户设置 | 入口改到「我的」。账户设置保留更名、归档、恢复、永久删除 |
| 统计分账本净值、收入分析、支出分析 | 模块写成「净资产」 | 标题改为账本净值、收入分析、支出分析。说明改为账本净值，不写完整家庭净资产 |
| 收支下分类、标签独立等权；保留筛选、下钻、显式多选 | 分类和标签同时铺开 | 收入、支出下用等权的「分类 / 标签」，一次只看一边。点行下钻。标签多选保留 |
| AI 从统计二级入口进入；保留旧单账户 AI | 已有两个按钮 | 统计 tab 默认全账本「AI 分析」。单账户「统计」仍打开该账户的「AI 分析本月」 |
| `EMPTY_PERIOD` 要有明确提示 | 生成错误显示通用失败句 | 映射为空期间提示 |
| 正红负绿、直接编辑、转账、余额调整不可编辑、方案 B | 既有页面已按此实现 | 本轮不改这些业务语义，也不做 `UAT-03` 或 MoneyWiz 式报表 |

没有发现必须停下来的冻结冲突。单账户统计页在成为 tab 后不能再带 URL 参数，账户上下文改由一次切换传入，AI 入口行为不变。
